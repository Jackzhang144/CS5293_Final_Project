# LLM Jailbreaks Presentation - React App

A React + MUI single-page application with PPT-style slide navigation.

## Setup

```bash
cd slides/react-app
npm install
npm start
```

## Navigation

- **Arrow Keys**: Left/Right arrows or Up/Down to navigate between slides
- **Space**: Next slide
- **Keyboard**: Left/Right arrows for navigation
- **Dot Navigation**: Click dots on the right side to jump to specific slides
- **Arrow Buttons**: Bottom-right buttons for previous/next

## Slides (12 Total)

1. Title - LLM Jailbreaks & Safety-Boundary Failures
2. Outline - Presentation Structure
3. Introduction - Capability vs Safety
4. Background - Alignment Methods & Failure Modes
5. Threat Model - Who Is the Adversary
6. Attack Taxonomy - Jailbreaking Attack Vectors
7. Defense Methods - Three Lines of Defense
8. Defense Comparison - Comparative Analysis Table
9. Evaluation - Benchmarks (HarmBench, StrongREJECT, JailbreakBench)
10. Open Problems - Future Directions
11. Conclusion - Key Takeaways
12. Q&A
